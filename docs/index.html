Build a recording with known labels.

MNE creates five virtual patients with background activity, interictal spikes, fast bursts, a seizure, and noisy contacts. The labels are known because the data are synthetic.

The current assistant uses Python rules. LLM agents, a clinical database, and an immutable run registry are future extensions.

02 / Look at the signal

A ranking is a starting point.
The waveform matters.

A large transient, a high-frequency burst, and a noisy contact can look very different in context. A single score cannot tell the whole story.

Onset connects each model’s ranking to selected signal windows, so you can explore what sits behind the output. These windows are examples associated with the score—not proof of a clinical conclusion.

05 / An open research foundation

A small prototype.
A larger set of questions.

Developed in the Brain–Machine Interfaces Lab at Nazarbayev University, led by Berdakh Abibullaev. Onset connects localization-model research with the practical work of presenting traceable evidence.

The code is open for students to inspect, reproduce, and extend. Explore the working app, or see the interactive design mockup for a proposed future interface.

Open source · MITSynthetic dataPatient-held-out evaluation
What is implemented, and what comes next?

Implemented: synthetic MNE recordings, bipolar features, two baseline rankers, leave-one-patient-out evaluation, deterministic reports, a rule-based assistant, and the Streamlit interface.

Proposed: authorized clinical-data ingestion, persistent versioned runs, access control, audit, and bounded LLM tools. The downloadable Qwen example is an optional teaching lab, not part of the live assistant. Clinical usefulness remains to be evaluated.
